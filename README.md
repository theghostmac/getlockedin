# LockedIn website

The landing page, themes, privacy policy and terms for [LockedIn](https://theghostmac.github.io/getlockedin/). Plain HTML and CSS, served by GitHub Pages and by Cloudflare Pages at lockedinapp.pages.dev: every push to `main` updates both (Cloudflare through `.github/workflows/deploy.yml`). Paths are relative so the same files work under `/getlockedin/` and at a root.
